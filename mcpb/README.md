# Social Champ for Claude

Connect Claude to **Social Champ** with one click. On first use, a browser window opens to sign in to Social Champ and approve access (**OAuth** — no API keys to paste).

Once connected, Claude can manage your social media: list channels and workspaces, create and schedule posts, generate AI content (posts, images, rewrites, hashtags), run bulk actions, control the publishing queue, manage labels, handle agency approval workflows, and create shareable calendars.

This extension connects to the hosted Social Champ MCP server at `https://mcp.socialchamp.com/mcp` via the `mcp-remote` bridge.

- Docs: https://developers.socialchamp.com/docs/mcp-guide
- Tool reference: https://developers.socialchamp.com/docs/mcp-tools

## Privacy Policy

This extension connects Claude to your Social Champ account over OAuth. See the Social Champ Privacy Policy: https://www.socialchamp.com/privacy-policy/
